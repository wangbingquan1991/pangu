## 五、指令（M3 所定）

| 中文名 | 对应 | 注 |
|---|---|---|
| 令 | 指令 instruction | 24 位，正合八卦 |
| 码 | 操作码 opcode | 令之高 6 位，正合一别卦；取**先天值** |
| 类 | 指令类别 | 码之上卦（位 23..21）。内务 0、存取 2、转移 4、数 6、器 7 |
| 操 | 操作 | 码之下卦（位 20..18）。器类之下卦，即算爻器之八操号 |
| 甲型 | R 型 | `[6 码][3 rd][3 rs1][3 rs2][9 偏]` |
| 乙型 | I 型 | `[6 码][3 rd][3 rs1][12 立即数]` |
| 丙型 | J 型 | `[6 码][18 地址]` |
| 偏 | 偏移 offset | 甲型之末 9 位，**符号扩展** |
| 立即数 | 立即数 immediate | 乙型之末 12 位；加减较符号扩，交并殊零扩 |
| 址 | 地址 address | 丙型之末 18 位，与计爻器同宽 |
| 器操 / 数操 | 器与器算 / 器与数算 | `0o70｜操`、`0o60｜操` |
| 程 | 手编之程序 | 见 `程.go`；非测试之私产，三者共用 |

**取\* 与 分\* 之别（必守）**：`取*` 入参是二十四位之**令**，
`分*` 入参是六位之**码**。混用则六十四卦尽落坤下——每一条令都会被解成 `䷁ 坤 停机 0`。
此病作者犯过，故志之。

## 五之二、译卦器之语（M4 所定）

| 中文名 | 对应 | 注 |
|---|---|---|
| 汇 | 汇编 assemble | 源码 → 机器码。跑**两遍**：一遍定址记签，二遍折值写码 |
| 汇一 | 单行汇编 | 只译一行，不纳标签与伪令；往返之验专用（穷举数百万次，不付 `汇` 之开销） |
| 反汇 | 反汇编 disassemble | 机器码 → **规范式**之列 |
| 反汇之文 | 反汇编为源码 | 委诸 `反汇`，不自起循环——**「规范式长什么样」只该有一处决定** |
| 令之译 | 令之规范式 | `加数 艮, 坤, 10`。**可回译**——`汇一(令之译(令)) ≡ 令` |
| 令之辞 | 令之 human 可读式 | `䷬ 萃 加数 艮, 坤, 10`。带卦符头，**不可回译** |
| 助记符 | mnemonic | 汉字（加数）或卦符（䷬），二者皆可 |
| 助记码表 | 名 → 码 | 由 `令名` 反推而造，**不由手抄** |
| 器号表 | 器名/卦符 → 号 | 由 `卦名`/`八卦符` 推出；16 条（八名 + 八卦符） |
| 伪令 | 汇编器之伪指令 | 二条：`处`（定址）、`字`（置一字之数据）。**机器从不执行** |
| 处 | `.org` | 定其后之码置于何址；跳址所留之隙为零 |
| 字 | `.word` | 径置一字之数据，不作令解 |
| 糖 | 语法糖 | 三元之跃、括号之式、省 rs1、省偏、省址、卦符三用、进制前缀 |
| 正体 | 规范式 | 反汇编所出者。**糖不可替换正体**——正体必在，糖方有归处 |
| **正体一律全写** | — | 一型几元便书几元，**纵为零亦不省**。甲型四、乙型三、丙型一。
  故人写「停机」，机器出「停机 0」；人写「加 震, 坎, 巽」，机器出「加 震, 坎, 巽, 0」。
  例外之单伏在格式化函数中，是债 |
| 变异 | mutation | 故意把 `译.go` 改错，看诸验能否杀之。今十六变异，十六皆杀 |
| 自检 | self-test | 注入一个**无害**之变异，验变异之器报「存活」——**量具亦须被量** |
| 验数之检 | — | 数一数包内实有几验、实跑几验，二者当同。防「有验从未被跑」 |
| 签 / 标签 | label | 以 `：`（或半角 `:`）结尾。不占机器之码 |
| 注 | 注释 | 以 `；` 起，至行末 |
| 元 | 操作数 operand | 以 `，`（或半角 `,`）分 |
| 过 | 诊断 diagnostic | 带行号与原文。**过而不止**：尽报诸过，不遇一即返 |
| 往返 | round-trip | `汇一(令之译(令)) ≡ 令`。译卦器之命脉 |

**标签之别（必守）**：甲型之偏是**相对量**（书标签则折算 `目标 − (本令址 + 1)`），
乙型之数与丙型之址是**绝对址**（书标签即其址，不折算）。
忘此别，则跳偏一个字——错，且错得悄无声息。

**卦符三用**：为助记（`䷬ 艮, 坤, 10` = 加数）、为器（`☵` = 坎器）、
为数（`䷃` = 10）。八卦符之值取先天序（`值 = 7 − (符 − 基)`，故 ☵ = 2）；
别卦符之码位是**文王序**，须过 `文王先天` 方成先天值（䷃ 蒙文王序第四，先天值 10）。

## 五之三、枢与叩之语（M5 所定）

| 中文名 | 值 / 义 |
|---|---|
| **枢基** | `0o777000`。枢之域之始，自此以上化态一步不许入 |
| **化之极** | `= 枢基`。化之域之上界（不含） |
| **叩之表基** | `= 枢基`。六十四槽，一槽一条 跃 |
| **变之表基** | `枢基 + 0o100`。三槽，一因一槽 |
| **枢文基** | `枢基 + 0o200`。枢之正文 |
| **器基 / 器之数** | `0o777770` / 8。器区，居藏之极 |
| **出之口 / 志之口 / 入之口** | 器区之 0 / 1 / 2 口。余五未配 |
| **叩之簿** | 叩号 → 名。今备其四：出 0、言 1、入 2、息 3 |
| **叩号** | 依名反查其号。名不在簿则 **panic**——宁可炸，不可默默取一个「大概对」的号 |
| **叩名** | 依号查其名。未备者回「未备」，越界者回空 |
| **字之文** | 一 24 位之字，作**一字之码位**观，还其为符（非三字节，见 `典/10` §八） |
| **置数** | 出「器 ← 大数」之二令：载高 + 加数。**乙型之立即数只有十二位有符号** |
| **启 / 化之签 / 化之程** | 上电第一令（降化）／用户程之签／以一段用户程配 启 与 枢 |
| **开天之源码** | 启 + 化 + 枢 合成一段源码，一次 汇 之 |

### 叩之约（ABI）

| 器 | 用 | 服务例程可坏否 |
|---|---|---|
| 乾 | 叩号 | **不可坏**——坏了则 回 之后用户不知自己求的何号 |
| 兑 | 元一，兼返值 | 可坏（其末值即返值） |
| 离 | 元二（今唯 言 用之，以志字数） | 可坏 |
| 艮 | — | 可坏：枢以之为**暂甲**（器基之所在） |
| 震 | — | 可坏：枢以之为**暂乙**（言之游标） |
| 坎 巽 | — | 可坏（今未用） |
| 坤 | 恒为零 | 不可坏 |

> **此表昔误**（M5 收档时发之）：旧表把 离 径列入「服务例程可坏之」，
> 而 `枢程.go` 之 `枢之身` 里，**言** 正是以 离 传字数、又自减而坏之。
> 表与码两处各说各话，而两者都不报错——**凡手抄之单，必漏**，此其一也。
> 今表由码出，不由记忆出。

### 变之约

变之处理器以 兑 志其因：**因 + 1** 而后志之。
故 兑 = 0 者是「无变」，非「越权」——若直接志 因，
则「无变」与「越权」同为零，二者遂不可辨。

## 六、文王卦序 ↔ 先天二进制映射表（已成）

> **本节已于 M3 前置之中补齐**（`典/07-卦序映射表.md`，提交 `9248dc1`）。
> 六十四卦在 Unicode 中按**文王序**排列（U+4DC0 为乾、U+4DFF 为未济），
> 而机器的操作码用的是**先天（二进制）序**。二者不是同一个排列，故须有映射表。

此表已从权威来源核对，非凭记忆手抄——Python `unicodedata.name()`
核得首位为 `HEXAGRAM FOR THE CREATIVE HEAVEN`、末位为 `BEFORE COMPLETION`。
`典/07` 附全表与核对之法；`卦序.go` 之 `文王先天` / `先天文王` 即其施行。

**凡显一别卦之符，皆用文王序**（人读之序）；
**凡算一码之值，皆用先天序**（机器算之序）。二者之间，唯此表是桥。
