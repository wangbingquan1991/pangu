# 07 · 文王卦序 ↔ 先天二进制映射表

> 此表是 M3 指令集的前置。操作码要落在六十四卦上，就绕不开它。
>
> **本表不凭记忆手抄。** 384 条爻线靠记忆必错。以下所记，是数据的来历、
> 两处独立来源的比对、以及六重结构校验之法——凡后来者欲改此表，
> 须先过这六重校验。

---

## 一、缘起：为何需要一张表

六十四卦在 Unicode 中（U+4DC0–U+4DFF）依 **文王卦序** 排列：乾一、坤二、
屯三……既济六十三、未济六十四。那是《易经》通行本的读诵之序。

机器所用的却是另一套：**先天之序**（邵雍传伏羲六十四卦次序）。此序中，
一卦之六爻自成一个六位二进制数——可计算、可运算、可寻址。

两套序之间的对应，**没有任何公式**。文王卦序的排列之理，古今聚讼，
迄今未有一个公认的数学解释（OEIS A102241 的注脚即明言「the orderings of
the hexagrams have not been explained mathematically」）。所以只能查表。

| 用途 | 用哪一套 |
|---|---|
| 卦符（U+4DC0 起）、卦名、诊断显示、反汇编 | 文王之序 |
| 操作码字段、地址字段、立即数字段 | 先天之序 |

## 二、数据来源（两处独立，逐项一致）

### 来源一 · 中文维基《六十四卦》

`https://zh.wikipedia.org/w/index.php?title=六十四卦&action=raw`
§「周易後天六十四卦」直列六十四个数，并明载两个要紧之处：

> 易經中卦的順序依序為：（將每一個卦由上而下看成二進位的數字
> （陽爻=1，陰爻=0），例如「火雷噬嗑」卦就是 101001₂ = 41₁₀）

一是给出了**位约定**（由上而下，陽=1），二是给出了一个**可验之例**
（噬嗑 = 41）。这个例子极要紧——它让「序列」与「位约定」互相锁定，
单有一者皆可自圆其说，两者齐备方能证伪。

### 来源二 · OEIS A102241

`https://oeis.org/A102241`

> Hexagrams of the Yi Jing interpreted in base 10, **with the top line = 2⁵
> (most significant bit) and the bottom line as 2⁰ (least significant bit)**.

六十四项数值**与来源一逐项一致**，且独立地确认了同一套位约定。

## 三、位约定之冲突与归化（此处最易错）

**外部文献以上爻为高位，本系统以初爻为高位。**

`象.go` 自 M0 便立下此约，且 `六爻符` 已据此实现：

```
位5 位4 位3 │ 位2 位1 位0
四爻 五爻 上爻 │ 初爻 二爻 三爻
──── 上卦 ────┼ ──── 下卦 ────
```

即 **别卦之值 = (上卦 << 3) | 下卦**，每一经卦自身之值沿用既有之约
（初爻为高位，值 7 为乾、0 为坤，Unicode 序位 = 7 − 值）。

两套约定的差距是**一次三爻位反转**：

| 卦 | 外部（上爻为高位） | 本系统（初爻为高位） |
|---|---|---|
| 乾 ☰ | 111 = 7 | 111 = 7（自对称） |
| 坤 ☷ | 000 = 0 | 000 = 0（自对称） |
| 离 ☲ | 101 = 5 | 101 = 5（自对称） |
| 坎 ☵ | 010 = 2 | 010 = 2（自对称） |
| 兑 ☱ | 110 = 6 | 011 = 3 |
| 巽 ☴ | 011 = 3 | 110 = 6 |
| 震 ☳ | 100 = 4 | 001 = 1 |
| 艮 ☶ | 001 = 1 | 100 = 4 |

归化之法：`值 = (rev3(上三爻) << 3) | rev3(下三爻)`，其中 `rev3` 为三位位反转。

**八经卦中只有四卦（乾坤离坎）不受影响，兑↔巽、震↔艮 两两互换。**
这个「四卦不变、四卦互换」的特征，正是最容易悄悄出错、又最难察觉的地方：
若只抽查乾坤坎离，怎么查都对。

> 本人在校表时，正是自己的**显示脚本**在这里摔了一跤——数据无误，
> 卦名却显示成「坤上坤下」。教训：显示与数据要用同一套约定，且必须
> 抽查非回文之卦。

## 四、六重校验

数据既已归化，以下六验尽在 `卦序_test.go` 中，凡改表须先过此六关。

| # | 校验 | 力在何处 |
|---|---|---|
| ① | **排列之验**：六十四值恰为 0–63 之排列，且两序往返可逆 | 防重复与失落 |
| ② | **三十二对之结构**：二十八对为综卦（位反转），四对（文王序位 1、27、29、61 起首）为错卦（逐爻互易） | 独立于来源的结构约束；整段偏移一位则尽破 |
| ③ | **自对称之卦**：颠倒一百八十度而不变者恰八卦，其文王序位恰在 1、2、27、28、29、30、61、62 | 六爻回文由前三爻定，故恰 2³ = 8 个；落在何处是文王序自身性质 |
| ④ | **八纯卦**：上下两经卦相同者恰八卦，其文王序位恰在 1、2、29、30、51、52、57、58 | 同③，且直接锁死经卦之值 |
| ⑤ | **名实互证**：二十五卦逐一核其卦名与上下二经卦 | **专破位约定之错**。所择尽是非回文之卦，且成对取其综卦（泰否、需讼、师比、屯蒙、既济未济、颐大过、中孚小过）——上下若倒，七对双双互换，验必破 |
| ⑥ | **爻象与倒置相合**：一卦之爻串，颠倒后当恰为原串首尾逆序 | 把 `别卦爻` 与 `倒置` 互锁：二者若用不同位约定，则「位反转」与「爻序逆转」不是同一件事 |

**关于⑤的选样**：八纯卦（乾坤坎离震艮巽兑）定死经卦之值——但其中乾坤离坎
是回文卦，验不出上下之倒；故必须再取非回文者。成对的综卦最有力：
泰与否互为颠倒，若上卦下卦整体互换，泰就成了否的样子。

## 五、取信与不取信

**取信**：两处独立来源逐项一致，且各自明载位约定并给出可验之例
（噬嗑 = 101001₂）。六重结构校验全过。

**不取信**：维基与 OEIS 皆非一手文献。若日后有更硬的依据（如核校
《周易》通行本卦序的整理本），当以之复核。此表若错，错的必然是
**卦名与卦符的对应**，而非结构——结构已由②③④锁死。

## 六、用法

```go
文王先天(21)   // 44    噬嗑之先天值
先天文王(44)   // 21    反查文王序位
别卦符(44)     // "䷔"
别卦名(44)     // "噬嗑"
别卦象(44)     // "☲☳"  离上震下
别卦爻(44)     // "⚊⚋⚋⚊⚋⚊"  自初爻起
上卦(44)       // 5     离
下卦(44)       // 4     震
倒置(44)       // 13    综卦（贲）
错卦(44)       // 19    错卦（井）
```

命令行 `./跑.sh run ./cmd/pangu` 的【五】段列出六十四卦全表。
