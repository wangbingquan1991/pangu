# 爻机规格

## 字长：24 位

24 位 = 8 卦 = 8 个八进制位。择此数的三条理由：

1. **24 是 3 的整数倍**，八进制与卦的边界永不撕裂。16 位做不到（16÷3 不可整除），
   这正是历史上 PDP-8（12 位）、PDP-11（16 位）用八进制书写机器码却又不尽顺手的原因。
2. **一个 24 位字 = 3 字节 = 正好一个 UTF-8 汉字**。基本汉字区 U+4E00–U+FFFF 与
   六十四卦符号 U+4DC0–U+4DFF 在 UTF-8 中各占 3 字节。按字寻址时，内存天然是「一字一汉字」。
3. **2²⁴ = 16 777 216 字 ≈ 48 MB 可寻址空间**，足够跑一个教学用的操作系统。

> **第 2 条之修正（M5 所发，务必读）**
>
> 「一字三字节」其言不虚，然**其言未尽**：
>
> ```
> UTF-8 三字节只容得 BMP 之内（十六位），U+FFFF 以外者一字节也放不下；
> 码位则不择——极于 U+10FFFF，需二十一位，而字有二十四位，绰有余。
> ```
>
> 故字里存的是**码位**，不是三字节。以码位为正，三字节为其用之一端：
> 出时按 UTF-8 编码成字节流付与串口，那是 出之流 的事，不是 字 的事。
>
> 此亦 M4 以来一贯之实践——`译.go` 之 `字 '道'` 取 36947 而非三字节，
> 演示与测皆以 `rune(v)` 观之。**是实践先定了码位，而此处之旧说未及追。**
>
> 此病之发现，是输出成了 `⟨0o00073330⟩` 而人以为乱码——
> 实则 0o73330 = 0x76D8 = U+76D8 = 「盘」。**机器一直是对的，是显示错了。**
> 详见 `典/10-枢与叩.md` §八。

## 寄存器

八个 24 位卦器，3 bit 编址，以八卦命名。约定：

- 坤（值 0）恒为零，写入无效——此即 RISC 风格的 zero register，可省去大量立即数指令。
- 余者 艮 坎 巽 震 离 兑 乾（值 1–7）为通用卦器。
- 「叩」（系统调用）的调用号置于**乾**寄存器，范围 `0o0`–`0o77`（0–63）。

> **「坤恒为零」已于 M3 实现。** 法在数据通路层：写允许 = 通用写允许 ∧ 全或(rd 域)，
> rd 域三位全阴（即坤）则全或为阴，写入被吞。卦器堆本身仍旧通用、不知此事。
> 如此只费八个择门，比在堆内译码省得多。

## 时序与存储（M2 所定）

**辰**：单一时钟，上升沿为有效之沿。诸器共用一根辰，不设门控时钟
（门控则各器时钟参差，一拍之内不齐）。详见 `02-实现约束.md` 第八戒。

**寄存器**：以 存允 择其入，诸器共用辰。复位另立 `总复` 一轨——
锁爻器之初态是「两出皆阴」的非法之态，收敛到哪一态全凭求值之序，
故上电之态不可恃，必先复位。

**藏**（存储器）：**同拍写入，随时读出**。

- 写：以址译出诸字之写允许，于辰之上升沿纳数。
- 读：纯组合，以址为择，改址即变，不待拍辰。

之所以读不设寄存器而写设之：读只求快，组合即可；
写必须对齐于辰，否则一拍之内所写之数尚未定，读已取走。

**计爻器**（程序计数器）：三途——载为阳则纳 入（跳转），
载阴而增阳则加一，二者皆阴则守。

## 指令格式（三种，皆 24 位）

```
甲型（寄存器型）  [6b 卦·操作码][3b rd][3b rs1][3b rs2][9b 偏移]
乙型（立即数型）  [6b 卦·操作码][3b rd][3b rs1][12b 立即数]     ← 12b = 4 个八进制位
丙型（跳转型）    [6b 卦·操作码][18b 地址]                       ← 18b = 6 卦
```

- **操作码 6 bit = 一卦**，正合六十四卦，操作码空间 64 条。
- **寄存器号 3 bit = 一经卦**，正合八卦，八个卦器。
- **地址 18 bit = 六卦**，可寻址 2¹⁸ = 262 144 字；配合段寄存器（或分页）覆盖 24 位空间。
- 甲型之 9b 偏移唯四条条件跃用之（相对 计，符号扩展）；算爻八操之器版用不到它，恒置零。

## 指令集（M3 所定）

### 编码之理：上卦定类，下卦定操

操作码六位取卦之**先天值**——即 `值 =（上卦 << 3）| 下卦`，一遵 `卦序.go` 之约。
于是在八进制之下

```
码 = 0o（上卦）（下卦）
```

这不只是好记，它是电路：乾类（0o70–0o77）的**下卦三位可以直连算爻器的择线**，
不费一个择门——因为下卦正是 M1 所定的八操。六十四卦之编码空间与 M1 的八操
在硅上严丝合缝地对上，是选择先天值而非文王序的唯一理由。

> 名近而实远者：地风**升**（0o03）是卦，算爻之**升**（下卦 5）是操，二者不相干。

### 扩展之约

- **存取之立即数恒作符号扩展**（地址偏移可为负向），不分载、存。
- 加、减、较 三操作符号扩展；交、并、殊 三操零扩展（同 RISC-V 之 andi/ori/xori）。
- 升、降 不用该域；载高 零扩展后置高十二位。
- 甲型之 9b 偏移恒作符号扩展。

`令.go` 之 `用符号(码)` 是此约在软件中的化身，`太极.go` 中有一根同名之线
「用符」是它在电路中的化身；`Test用符与电路相合` 专验二者不悖。

### 三处易错（已定，不可擅改）

1. **胜跃是「≥」不是「>」。** 名曰「胜」，义为「不小于」。
   这是被电路逼出来的：算爻器的 `较` 产出 `rs1 < rs2 ? 1 : 0`，
   而条件测试取的是「果为零」这根现成的线，`¬（rs1 < rs2）` 即 `rs1 ≥ rs2`。
   若要严格的「>」，把卦器堆的两个读口对调即可（六个择门），但本轮不取。
2. **志之可用者有界。** 进位、溢出二志唯加、减二操有意义，
   交／并／殊／升／降／较 所出之进位、溢出无定义，程序不得依赖。
3. **坤恒为零是写入被吞，不是读出为阴。** 写坤之令照常执行（仍走完写回一途），
   只是写允许被 `全或(rd域)` 压成阴。副作用（如 `较` 之志）照常发生。

## 位序之约（重要）

本系统同时存在两套位序，二者互为镜像，**不可混用**：

| | 序 | 用途 |
|---|---|---|
| 数值位序 | 入[0] 为最低位（权重 2⁰） | 一切运算、地址、立即数、指令字段 |
| 卦象位序 | 初爻（最下爻）为最高位 | 卦符的显示与书写，即邵雍先天之序 |

转换一律经由 `象.go` 中的 `排爻` / `并爻` / `倒爻` 完成，其余各处不得自行换算。

之所以并存两套，是因为它们各自有不可放弃的来源：
数值位序来自二进制数制的通例，卦象位序来自 Unicode 卦符的既有排布
（经核验：U+2630 起为乾兑离震巽坎艮坤，值与序位恰为 `序位 = 7 - 值`）。

## 八进制的地位

**八进制不需要「模拟」，它就是二进制。** 三位一组的记法，无损可逆。
八卦 = 3 bit 在数学上精确成立，不是比喻。

真正的约束在别处：现代计算机的字长（8/16/32/64）都不是 3 的倍数，
所以八进制在通用机器上只作为**书写记法**存在，不构成硬件事实。
爻机取 24 位字长，正是要让八进制从记法升格为**结构事实**——
每一个 24 位字，自左至右恰好是八个卦。

## 内存映射 I/O（M5 已定，M6 拓之）

器区居藏之极，**十口**（M6 自八口拓之），**是口，不是址**——写它不入藏。

| 址 | 名 | 读 | 写 |
|---|---|---|---|
| `0o777700` | **出** | 得零（只写不读） | 即出一字 |
| `0o777701` | **志** | 非零则可出，恒为阳 | 无物受之 |
| `0o777702` | **入** | 得一字，无则阴 | 无物受之 |
| `0o777703` | **钟** | 已过之令 | 置时间片之**令数**（零则不鸣）（M6） |
| `0o777704` | **告** | 有告待理否 | 阳则举告，阴则销之（M6） |
| `0o777705` | **界基** | 现化之界基 | 无物受之（只可读）（M6） |
| `0o777706` | **界限** | 现化之界限 | 无物受之（只可读）（M6） |
| `0o777707` | **当化** | 现化之号 | 无物受之（只可读）（M6） |
| `0o777710` | **化选** | 所择者之号 | 择其化（号越界亦收，不陷）（M6） |
| `0o777711` | **化可** | 所择之化可行否（越界则阴） | 无物受之（M6） |
| `0o777712`–`0o777777` | — | 得零 | 无物受之 |

`器之数` 自八拓至 `0o100`（六十四），而**只配其十**，余五十四留 M7 之外设。
何以拓这么多而不只拓二：**口之数当留余**，犹 叩之表 之留六十四槽。
若每次增一口便移一次 器基，则 器基 之址遂成一串手抄之数。

`器口之簿` 是**唯一真源**：`器口之数()` 由它数出。
若另抄一份名单，则增一口而表不变——而那不变不报错，只是少了一行。

## 特权与爻变（M5 已定，M6 拓之）

**特权两态**：化态（用户）/ 枢态（内核）。上电在枢态。

**化态之禁**：取指不入枢之域（检在取指**之前**，否则码已泄）、
读写不入枢之域、不行特权之令（降化、回、转化、化息）、
**不越其化之界**（M6）。犯禁者**先撤其效，再陷**（存取之事）。

**爻变五因**（M6 自三因拓之）：越权、越令（未定之码）、越号（叩号越出六十四）、
**越化**（转化 之号越出诸化、或其化非行）、**告**（异步之断）。

| 址 | 表 | 容 |
|---|---|---|
| `0o776000`–`0o776377` | **节表** | 八节，一节 `0o40`（三十二）字（M7） |
| `0o776400`–`0o776410` | **籍存** | 核之暂名之区，比名时用（M7） |
| `0o777000`–`0o777077` | 叩之表 | 六十四槽，一槽一条 跃 |
| `0o777100`–`0o777104` | 变之表 | **五**槽，一因一槽（M6 自增其二） |
| `0o777105` 起 | 枢之正文 | 叩之服务例程、变之处理器、**序**（M6）、**籍**（M7） |

二表皆**码**，非索引：一槽便是一条 跃 令，故反汇编可见其全形，
而 叩 之一事遂与诸令同列——它不特权的什么，它只是被跳到。

**枢之域之始 `枢基 = 0o777000`**。留 `0o1000`（五百一十二字）与枢，
恰是藏之 1/512——一个「刚好够放一张表和几段处理器」之数，不是一个圆整好看之数。

> **M7 之改**：枢文基 旧作 `枢基 + 0o200 = 0o777200`，而 变之表 只占五字，
> 其间 0o73（五十九字）遂白弃。今 `枢文基 = 变之表基 + 变之数 = 0o777105`，
> 余地自增 59 字——籍之码便是从那道隙里捡回来的。
> 址既由 变之表 算出，则表若长，正文自随，不须有人记得去改 0o200 这个数。

又：**枢之域不止枢一部**。M7 立籍区于 `0o776000`，居 枢基 之下，
故 **化之极（化态之所能触者之上界）＝ 籍基 ＝ `0o776000`**，不由 枢基 出。

全案见 `典/10-枢与叩.md`、`典/12-籍与目.md`。

## 化与序（M6 已定）

**界址（基址＋限长）**：一化之域由其 界基 与 界限 定之。

```
物址 = 界基 + 虚址        （0 ≤ 虚址 < 界限）
物址 = 界基               （虚址 ≥ 界限，越界者回 界基，其笔随即被撤）
界基 = 化之域 × (号 + 1)   （由号算出，不由调用者传）
```

一式而得二物：**屏**（一化写不到他化之域）与**重定位**
（两化可用同一段码而各安一处，码不必改一字）。

**化块**（PCB）一化一簿：

| 项 | 义 |
|---|---|
| 号 | 第几化。**界基 由它算出，故二者不容各记一份** |
| 状 | 化行 / 化毕（今止二状；「眠」待 M7 有外设可待方立） |
| 界基 / 界限 | 此化之域之起点（物址）与大小（虚址之上界） |
| 诸器 | 化态之现况。化不跑时，器在此处 |
| 计 | 化态之返址（虚址），亦变之栈之**底** |
| 栈 | 枢态嵌套之陷所压之处 |

**器与计只有一处安身**：化在跑时，器在卦器堆里、计在计爻器里；不跑时皆在块里。
**底在块，深在栈，二者不叠**——化态之陷存入块，枢态之陷压一层于栈。

**序**（调度器）**是码，不是 Go**：二十条令，以译卦器之语自陈，装入 `枢文基` 起处，
由 变之表 跃入。Go 那一侧没有一行调度逻辑。
序 **先问而后转**：先择其化（化选之口），问其可行否（化可之口），不可行者径过。

**钟**（时间片）：片 之单位是**令**，不是拍。一条令有取指、执行两拍，
而 过 只在取指相累加。**先判后加**——过 是「已得几令」，非「将取第几条」。
片 为零则不鸣（协作式）；钟既置，方是夺权式。
`转化` 之后 `过 ← 0`——**新化得一整片，不承旧化之余。**

**告**（异步之断）：来路有二，皆归于 告之口——**钟鸣**（时到自鸣）与**举告**（软断）。
**其变不耗一令**：告 是在两令之间被采样的（只于取指相问之）。
**销其告者，陷也，非处理器也**——若待处理器自销，则销之未及而 回 已出，告遂复鸣。

全案见 `典/11-化与序.md`。

## 「叩」之六十四号（M5 已定其四）

`叩之簿` 是唯一之真源：叩之表之六十四行由它生成，诸号之常量由 `叩号` 反查得之。

| 号 | 名 | 义 |
|---|---|---|
| 0 | 出 | 出一字于串口。兑 = 欲出之字 |
| 1 | 言 | 出一串。兑 = 首址，离 = 字数；返 兑 = 0 |
| 2 | 入 | 入一字。返 兑 = 所入之字，无则零 |
| 3 | 息 | 停机。兑 = 退出之码 |
| 4 | 建 | 建档。兑 = 名之首址，离 = 名字数；返 兑 = 节号，重名或籍满则 −1（M7） |
| 5 | 求 | 求档。兑 = 名之首址，离 = 名字数；返 兑 = 节号，无则 −1（M7） |
| 6 | 写 | 写档。兑 = 节号，离 = 源址，坎 = 字数；返 兑 = 实写之字数（M7） |
| 7 | 读 | 读档。兑 = 节号，离 = 目址，坎 = 字数；返 兑 = 实读之字数（M7） |
| 8 | 删 | 删档。兑 = 节号；返 兑 = 零，无此档则 −1（M7） |
| 9 | 目 | 录其名。兑 = 节号，离 = 目址；返 兑 = 名字数，无此档则 −1（M7） |
| 10–63 | 未备 | 跃于同一处 `叩未备`，返 兑 = −1 |

**簿中增一名，表自长出一槽，枢之身亦自长出一节**——
三者皆由一簿推出，不劳手改，亦无处可漏。

### 叩之约（ABI）

八卦寄存器之用，叩 与 化 之间之约：**兑 元一兼返值，离 元二，坎 元三，震 元四**。

叩 可坏 艮、坎、巽、震、离——**化态之器过不得一次叩**。
坤 恒为零，乾 是叩号，故八器之中可用者六。

## 籍与目（M7 已定）

**一节（inode）三十二字**，四域：

```
0o00  名   0o10 字，末以零终  ⇒ 名之极 七字。不另记长——名之有尽，在其字中
0o10  长   据之字数
0o11  志   零则未用，非零则在用
0o12  据   0o26（二十二）字，正文
```

```
节之度   = 0o40
节之移   = 5              （节之度 ＝ 1 << 节之移）
节数     = 0o10
节址     = 籍基 + (号 << 节之移)
```

**籍之六叩皆以节号为凭，不以节址为凭**——
节址 是枢之址，它若落回化态之手，化 遂持一柄枢门的钥匙。
**与其验其址，不如不与之址。**

**壳**（命令解释器）**亦是一「化」**：行不得特权之令，触不到枢之域，
所能者唯 叩 而已。六令：列 建 写 读 删 止；三色之报：成 否 无。
**壳之尊，不在其权，在其为第一个用 叩 说话的程。**

全案见 `典/12-籍与目.md`。
