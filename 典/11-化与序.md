# 化与序 · M6

> **验收**（`典/04` 原文）：两个「化」交替运行，各自的内存互不干扰。
>
> 已达。跑 `./跑.sh test -run Test片则轮转 -v`：
>
> ```
> 片 1：出「甲乙甲乙甲乙乙乙」，告 114 次
> 片 8：出「甲乙甲乙甲乙乙乙」，告 13 次
> ```
>
> 而二者之 **和** 与 片 ＝ 0（协作式）者分毫不差：
> 甲 3 × 30002 ＝ 90006，乙 5 × 20057 ＝ 100285。
>
> 「互不干扰」不是靠两化各用一址——那是理所当然，验不出什么。
> 此验**故意让两化用同一个虚址**（`化和址`），
> 而它们各落在 `0o000140` 与 `0o000240` 两处物址上，各是各的指纹。
> 界址若不施，两化之争便落在 `化和址` 本身，而那个址之值为零——
> `Test同址而异物` 正守在此处。

## 二、三岔：界址、告、栈

M6 之难在**上下文切换**，不在内存保护。故开工之前先把三件事定了：

| 岔 | 所择 | 所不择 | 何以 |
|---|---|---|---|
| 内存之屏 | **界址（基址＋限长）** | 分页（虚境） | 分页须一次引入页表、址之变换、缺页之变、写页表之令**四样新物**。把两件难事塞进一个里程碑，是让它们同时变难 |
| 夺权之由 | **器区增「告」之口** | 只有同步之陷 | M5 之遗留已志：无「告」则外设有事无从叩枢，而调度无所由夺 |
| 变之栈 | **M6 即立** | 留 M7 | M5 之「枢态之变只能轰」，其根在 存计 只有一个。栈不立，则 序 之中 转化 不就便要轰其机——**序 自己就得先死** |

分页留 M7。其故非为分页难，而为**彼时有真实的用处驱动它**：
籍（文件系统）要 mmap、要共享，那时分页是**被叫来的**；
为分页而分页，是为一个尚未出现的需求付账。

## 三、界址：基址＋限长

```go
func (k *枢机) 变换(址 int) int {
	k.虚址 = 址
	if k.特权 == 枢态 {
		return 址 & 址掩
	}
	块 := k.化[k.当]
	if 址 < 0 || 址 >= 块.界限 {
		return 块.界基 & 址掩
	}
	return (块.界基 + 址) & 址掩
}
```

一式而得二物：

- **屏**　两化之 界基 不同，则一化写不到另一化之域里去——此即验收之「互不干扰」。
- **重定位**　两化可用**同一段码**（皆自虚址 0 起）而各安一处，码不必改一字。

### 而重定位是意外之得

M4 遗留了一笔「重定位之表」的债：译卦器所出之码恒自址 0 起，
装到别处则须改码中之址。界址既立，此债**不须还而自消**——

> 重定位者，改码中之址也；界址者，挪码之根也。
> **改码则码有二份（原本与改本），挪根则码恒一份。**

`装化` 因此只是「把同一串字写到另一个起点」，一字不改：

```
化 0：界基 0o000100，界限 0o100   →  物址 0o000100 .. 0o000177
化 1：界基 0o000200，界限 0o100   →  物址 0o000200 .. 0o000277
```

界基 **由号算出，不由调用者传**：`界基 = 化之域 × (号 + 1)`。
若调用者手传，则「第几化」与「在何址」遂成两事，而其一必朽（M4 之训）。

### 越界者回 界基，不回其虚址

越界则回 **界基**（虚址零之物理所在）为物址，非为真的要去读它——
只为给 L2 一个**不泄枢密**的去处，那一笔读或写随即被 撤 掉。

若径以虚址为物址，则化态便真能读到枢之码：**纵撤其值，其线已通，
而线通之一瞬，便是屏破之一瞬。**

### 同址而异物

两化之 和 都在**同一个虚址** `化和址` 上。故：

- 物址 `化计址`/`化和址`/`化次址`/`化字址` 本身，当**恒为零**。
  若界址不施，两化之争便落在此处，而此址遂非零。
- 和 累加的是**其字**，不是恒加一。恒加一则 和 恒等于 计，
  纵屏破亦只错在数上，**验不到「其字」**。

> `和 ← 和 ＋ 其字`，则 和 是此化之**指纹**：
> 甲（U+7532 ＝ 30002）三回当 90006，乙（U+4E59 ＝ 20057）五回当 100285。
> 屏若破，两化争写一址，和 遂成 190291——甲不是，乙也不是。

### 一处旧病：守错了址

`Test化态写枢之域则撤` 曾守在 `枢基` 上。界址既立，越界之写
被 变换 引去了 界基，**根本没落在 枢基 上**——那一断言遂恒真，
而**恒真的断言与没有断言同**。它安静地绿了整整一个里程碑。

今改为**抄下整片 藏 而比之**，`Test越界者毕而他化续行` 又守 化 0 之域首。
两验夹之，变异七（越权之写 不撤）方杀得死。

### 界同而问法异：取指 与 存取

**同是问界，问法因时而异**，而其界则一——皆自 `化块之界限` 出：

| 何时 | 变换 已行否 | 以何问之 |
|---|---|---|
| 取指 | 未行，虚址 未记 | `是化之域(计)` —— 址 ≥ 0 且 址 < 界限 |
| 存取 | 已行，虚址 已记 | `越界否()` —— 虚址 < 0 或 虚址 ≥ 界限 |

两条路缺一不可。故 `化之越界源`（越的是存取之址）之外，
另立 `化之越取源`（越的是取指之址）：出一字而 `跃` 出其域。

其 越址 正当 `化之域`（＝ 界限）——**第一个出界之址**，恰在界外一线。
取界内之址则取指本不越界，此验遂无所验。

### 一处真病：由果抄果（第三发）

变异卅四「取指之检 改由 化之极 出」初跑**存活**。其故：

> 上电之化 界限 ＝ 化之极，二者同指，
> 故 `是化之域(计)` 与「计 ≥ 化之极」在那具机上**恒等**——
> 改了一个，旧验一条也杀不着。

化之极 是「无化之时」那一界，是**果**；化块之界限 是「此化有多大」，是**因**。
M5 之二戒「由因出果，不由果抄果」此是第三发（前二发：`是枢之域`、此界）。
故另立 `Test取指越界者毕而他化续行`，以 `建序机`（界限 ＝ 0o100）
代 上电之化（界限 ＝ 化之极 ＝ 0o777000），二者相去甚远，改之立见。

#### 注入之后，它是怎么红的

实测之状与初料**相反**，故特志之：

```
跑：20000 拍之内机器未止（计 0o023506，特权 化态，令 0o20600043）
```

出界之址经 变换 **一概被引入 界基**（「越界者回 界基」），故远近无别——
化 0 遂自取其域首之 `载字`（一条无害之令）而空转，计 日增而令 不变。

初注曾谓「越址当落在次化之域首，那里是能跑的码」，**实测不然**；
注已改。此亦一诫：**注里写的机制，须与跑出来的相符，不然便是下一篇谎。**

#### 望箭

`和 ＝ 0` 与 `计 ＝ 0` 那两条断言，今日**并非杀敌之器**——
化 0 空转于 `载字`，本就不曾累加，故纵取指失守，此二断言亦绿。
杀它者是 `跑必止`。

所以留之者：若他日 变换 改约（分页既立，越界者径以虚址为物址），
则化 0 遂真取到别化之码上去跑，而 和 立时为「甲」之码位 30002。
**望箭不发则已，发则中的。** 故其注中特书「此是一支望箭，非今日杀敌之器」，
免后人误以其为凭。

## 四、化块：一化一底

```go
type 化块 struct {
	号  int
	状  化状
	界基 int    // 物址 ＝ 界基 ＋ 虚址
	界限 int    // 虚址须小于此
	诸器 [8]int // 化态之现况
	计  int    // 化态之返址（虚址），亦栈之底
	栈  []变记   // 枢态嵌套之陷
}
```

**器与计只有一处安身。** 化在跑时，它的器在卦器堆里，它的计在计爻器里；
化不跑时，它的器与计在块里。二者不容同时有两份——
化态 一陷，诸器与计即存于此；转化 一至，即自此复。
故「上下文」不是一份抄本，而是一处**唯一的所在**。

### 底在块，深在栈，二者不叠

| 来处 | 所记 | 故 |
|---|---|---|
| 自化态 | 诸器 与 计 **存入化块** | 化态之陷只会有一次（陷后便是枢态），故一处足够 |
| 自枢态 | **压一层于变之栈** | 嵌套之陷，回 时层层弹出 |

何以化态不压栈：化态之陷，其来处便是**化之继绪**，
而化之继绪只该有一处（块之计）。若亦压栈，则化之来处遂有二份，
而 回 之时不知该从哪一份。

> 栈底在块，不假压栈而有。化之初生而未尝陷者，回 亦知其所归。

`Test告则不压栈` 专守此条：逐拍步进至 因 ＝ 告 之刹那，查其栈——当空。
**先跑后查则查不到**：其时 回 已行、栈已空，看不出它究竟空在何时。

### 化状只有二：行，或毕

何以不立「眠」（待一事而寤）：**M6 无一事可待**。
外设未至，无断可候，故 眠 无源——立之则成一枚永不可达之状，
而诸验亦无处验它，变异之器遂杀它不死。
`可行否` 一式已留其门：他日 化眠 既立，「眠」亦归不可行，而此式不改。

## 五、序：先问而后转

```go
序之始：  载字 震, [艮 + 当化之口]      ；震 ← 当
          加数 坎, 震, 0               ；坎 ← 候选，起于 当
          加数 巽, 坤, 化数             ；巽 ← 化之数
序环：    加数 坎, 坎, 1               ；候选 ← 候选 ＋ 1
          逊跃 坤, 坎, 巽, 序问         ；犹在化内则径问，否则绕回域首
          加数 坎, 坤, 0
序问：    等跃 坤, 坎, 震, 序本         ；绕了一圈而复归于当 → 回视其本化
          存字 坎, [艮 + 化选之口]      ；择 化 候选
          载字 离, [艮 + 化可之口]      ；离 ← 其化可行否
          等跃 坤, 离, 坤, 序环         ；不可行则试其次
          转化 坤, 坎, 坤, 0            ；可行则转之
          回 0                         ；回 → 其化（栈空则归于块之计）
序本：    …（绕完一圈，试其本化）
序穷：    停机 0                        ；诸化皆毕，机无所事
```

**序 是码，不是 Go。** 二十条令，由译卦器汇出、装入高址、由 变之表 跃入。
Go 那一侧没有一行调度逻辑——此与 M5 之「枢何以是码」同一条约。

### 何以先问而后转

转化 是特权之令；号越出诸化、或其所指之化非行，皆陷 **越化**。
而 越化 是**枢之过**，其处理器止其机。
序 若径转而问之于后，则它自己就会把机轰掉。

故 **化可之口** 立：先择其化，问其可行否，不可行者径过。

此处又有一戒：**化可 越界则答阴，不陷**。
若越界者陷，则 序 遂须先问「有几化」——那便又要一口，
而那一口之数，终将与 Go 之 `len(k.化)` 成为两份。
**不问则已，问则必有一答，答不出便答「不可」。**

### 一处瞎处：转化 之 越化 走不到

序 既先问而后转，则 越化之变 **序 走不到**；今之枢亦无别处行 转化 者。
一条走不到的路，跑一万遍也是验不到——它不报错，只是一遍遍地绿。

故 `Test越化之变则止` 不假 序，径自枢态行之（两案：号越出诸化、所指之化非行）。

### 序 不坏 兑

变之处理器 以 `兑 ← 因 ＋ 1` 志其因，而 **序 不用 兑**——
故此志得过 停机 而存，诸验遂得于机止之后观 兑 而知其因。
此非巧，是一条小约：**谁也不许动别人的寄存器，除非约里写了。**

## 六、钟：片之单位是令，不是拍

```go
type 钟 struct {
	片  int  // 时间片之令数；零则不鸣
	过  int  // 化态已过之令
	告待 bool // 有告待理否
}
func (c 钟) 鸣否() bool { return c.片 > 0 && c.过 >= c.片 }
```

**片 为零则不鸣**——上电之机无钟，须枢自置其片。
此非缺省之便，而是志一条实情：无钟之机不夺其化，
化 之让与不让，悉听其便（**协作式**）；钟既置，方是**夺权式**。

何以单位是「令」而不是「拍」：一条令有取指、执行两拍，
而 过 只在取指相累加。若以拍计，则同一段码在 L1 与 L2 上要跑出两个结果——
**时间片之数若系于门之快慢，它量的便不是时辰，是器件。**

### 先判后加

```go
if 旧相 == 0 && 旧特权 == 化态 {
	if k.告至() { … 陷（告之变）… ; return }
	if k.钟.片 > 0 {
		k.钟.过++
	}
}
```

过 是「此化**已得**几令」，非「将要取第几条」。
先加后判，则 过 在尚未执行之令的取指相上就已递增——
于是 **片 ＝ 8 者只得 7 令**，少一条，且不报错。

其差止一条令，而**片 之数遂名不符实**。此即「错而无声」之类，
变异卅九专守之：片 ＝ 1 之下，先加后判者遂令**一条令也执行不了**，
机 空转于「陷 → 序 → 转化 → 回 → 陷」之环而永不进。

### 告之陷不耗一令

告 是在**两令之间**被采样的（只于取指相问之），故一令之执行不被腰斩。
`Test告之陷不耗一令` 以 片 ＝ 0 与 片 ＝ 1 相较：
片 ＝ 1 之下全程告 **114 次**，而两化之 计、和、出之字数**一毫不差**。

> 一百一十四次夺权而未失一令，此即「不耗」之实据。

#### 何以比的是集合，不是出之文之序

序 之序自当因 片 而异——那正是轮转所欲。故 出之文 之序**必不同**，
比之则此验恒红，而红得毫无意义。所同者当是其果：
甲 出几个甲、累加几回、和是多少。

### 转化 则复其钟

`转化` 之后 `钟.过 ← 0`——**新化得一整片，不承旧化之余。**
若承之，则新化之头一片遂短了，短多少全看旧化是何时被夺的：
诸化之片遂不等长，而「片 之数名副其实」之约成虚言。

此条之所以可验，端赖 `Test转化则复其钟` **径自枢态呼 行转化**——
序 之中造不出一个「不等于 片」的 过（钟鸣之时 过 恰是 片），
故假 序 观之则量不到此处。**量具够不着的地方，须另立一具。**

## 七、告：异步之断

```
器区之口：告（0o04）
  读　得「有告待理否」（阳则一）
  写　阳则举告，阴则销之
```

告 之来路有二，二者皆归于一口：

- **钟鸣**　时到自鸣。此是**同步**之夺（虽由异步之器件起）。
- **举告**　枢 或他化 写阳于 告之口，告立至。此是**软断**，备他日外设之用。

### 举 → 至 → 陷 → 销

四节缺一则不成为断。`Test器区之化口` 全程量之：

1. 举　`器写(告之口, 1)`
2. 至　`告至()` 为真，`器读(告之口)` 得 1
3. 陷　化态之下一取指，陷 **告之变**（不耗一令）
4. 销　**销其告者，陷也，非处理器也**——`k.钟.过, k.钟.告待 = 0, false`

全程当**恰告一次**。若不销，则化态每一取指皆陷，
机 遂空转于「陷 → 序 → 转化 → 回 → 陷」之环而**一令不进**。
那是死环，不是错；而死环在 跑 之上限之下看起来只是「跑不完」。
变异四十专守之。

### 变之处理器 分三途

| 因 | 谁的过 | 处理器之所为 |
|---|---|---|
| 越权、越令、越号 | **化之过** | 化息（死其化），然后 序 |
| 越化 | **枢之过** | 停机（不死其化——化 是无辜的） |
| 告 | **非过** | 序（径转，不罪不奖） |

M5 之「枢态之变则轰」于 M6 **撤去**：栈既立，来处覆不了，
无可救者遂只余一途——**变栈之极（8）**。
栈溢者，连「往哪里陷」都已无处可记，此是真无可救，非「懒得救」。

| 7 | 当化 | **M6 增**：现化之号。只可读 |
| 8 | 化选 | **M6 增**：写之择其化（号越界亦收，不陷），读之得所择者之号 |
| 9 | 化可 | **M6 增**：读之得**所择之化**可行否。越界则阴 |

`器之数` 自八拓至 `0o100`（六十四），而**只配其十**，余五十四留 M7 之外设。
何以拓这么多而不只拓二：**口之数当留余**，犹 叩之表 之留六十四槽。
若每次增一口便移一次 器基，则 器基 之址遂成一串手抄之数，
而 枢文基 与其之间那一段（枢之正文之长短）便日日不同。
今 器基 定于 `0o777700`，可坐而不移——而 `器基 + 器之数` 仍恰是 `址掩 + 1`。

**器口之簿 是唯一真源**：演示 之器区表与 `器口之数()` 皆由它出。
若另抄一份名单，则增一口而表不变——而那不变不报错，只是少了一行。
`Test器口之簿` 量的是**其数与其簿相合否**，非其数本身。

## 十一、M6 之四戒

1. **底在块，深在栈，二者不叠。** 化态之陷存入块（化之继绪只该有一处），
   枢态之陷压于栈（嵌套可有多层）。若化态亦压栈，则化之来处遂有二份，
   而 回 之时不知该从哪一份——它不报错，只是**和 少了几分**。
2. **量具够不着的地方，须另立一具。** 序 走不到的路（越化之变）、
   序 中造不出的数（不等于 片 的 过）、上电之化 界同而名异的界（取指之检），
   皆不得假 序 或假 上电之化 以观之。一条走不到的路，跑一万遍也是验不到。
3. **表若说的是另一件事，它便是谎。** 器口之簿 是唯一真源，
   `器口之数` 由它数出；凡另抄一份名单者，增一口而表不变，
   而那不变不报错，只是少了一行。
4. **注里写的机制，须与跑出来的相符。** 一验杀了一个变异，
   不等于它按你以为的那个理杀的。`化之越取源` 初注谓「越址当落在次化之域首，
   那里是能跑的码」，而实测是 变换 把它引回了 界基、化 自取其首令而空转——
   注与实**相反**。注若与实不符，那注便是**下一篇谎**：
   后人读之，据以改约，而祸在别处。
   故凡志机制于注中者，**先跑一遍，看它究竟是怎么红的**。

（此条已入 `读我.md` 之**戒十一**：验「某件事没有发生」者，
须先自问「若它发生了，会落在哪一址」——守错了址，则纵一无所有，验也是绿的。）
